Локальные копии ответов Figma API (MCP figma-api / Framelink), чтобы не запрашивать макет повторно.

- Разбор узла: `npm run figma:tree -- <nodeId>` — узел ищется во всех выгрузках `.figma/*.yaml` (можно указать `--file`).
- Сверка страницы: `npm run compare:page -- <страница>` — секции описаны в `sections.json`.

- Файл: `xDnfQshLiYi4kvHbeJfZav` — Laress (Copy): десктоп всех разделов (выгрузки `966:*`).
- Файл адаптивов: `ttzrfVDjpmBVcb9dRRhXIj` — тоже «Laress (Copy)», в нём к десктопу дорисованы планшет 768 и мобильная версия 375 (выгрузки `1311:*` и дальше). См. раздел «Адаптив» в конце.
- Имя кэша: `<что>_<nodeId>.yaml`, скриншоты-эталоны: `screenshots/<что>_<nodeId>.png` (1x)
- Если дизайнер менял макет после даты выгрузки — выгрузить узел заново и обновить дату.
